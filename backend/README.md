somewhere to land, and deliberately contains no implementation.

```
backend/

├── models/        # mongoose schemas                 (empty)
├── routes/        # route definitions                (empty)
├── services/      # business logic                   (empty)
├── utils/         # helpers                          (empty)
├── app.js         # application wiring     (stub)
├── server.js      # entry point            (stub)

```

Not yet implemented, by design: MongoDB, APIs, authentication, controllers,
models, email, payments, admin dashboard, database connection.
